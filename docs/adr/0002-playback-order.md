# Playback order of the form

The music is written once and `Score::play_order` decides which bars sound and in what order. After a D.C./D.S., repeats are not taken and the last ending of each group is played, following the usual classical practice. Each jump is taken once and the path has a safety limit. A D.S. without a segno or an «al Coda» (To Coda) without a coda is ignored, so that an incomplete form can be written without blocking editing.
