# Orden de interpretación de la forma

La música se escribe una vez y `Score::play_order` decide qué compases suenan y en qué orden. Tras un D.C./D.S. no se toman las repeticiones y se toca la última casilla de cada grupo, siguiendo la práctica clásica habitual. Cada salto se toma una vez y el recorrido tiene un límite de seguridad. Un D.S. sin signo o un «al Coda» sin coda se ignora para permitir escribir una forma incompleta sin bloquear la edición.
