# Clear ribbon: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redraw and reorganize Levare's ribbon according to the approved mockup: a single control grammar, visible name and key, and tabs by task.

**Architecture:** The ribbon already separates data (`crates/toolbar/src/spec.rs`), projection with folding by width (`crates/toolbar/src/project.rs`) and GPUI drawing (`crates/app-gpui/src/ui/toolbar.rs`). Task 1 changes the data and the tabs, Task 2 the projection, Task 3 the drawing and Task 4 the documentation and the visual check.

**Tech Stack:** Rust 2024, GPUI `=0.2.2`, crates `score-toolbar` and `score-keymap`.

**Spec:** [docs/superpowers/specs/2026-10-26-ribbon-design.md](../specs/2026-10-26-ribbon-design.md). Content reference (names, glyphs, keys and tooltip sentences of each control, group by group): the `TABS` array of [docs/superpowers/specs/2026-10-26-ribbon-mockup.html](../specs/2026-10-26-ribbon-mockup.html).

## Global Constraints

- Published command IDs do not change (`docs/development.md`); only labels change. New command: a constant in `id::`, an entry in the registry, a branch in `AppView::run`, `docs/shortcuts.md` regenerated with `LEVARE_UPDATE_SHORTCUTS=1 cargo test -p score-keymap`.
- Colors only from `crates/app-gpui/src/ui/theme.rs`; no new literal colors.
- Interface texts in Spanish, in sentence case; identifiers in English.
- `cargo fmt --all --check`, `cargo test --workspace --locked` and `cargo clippy --workspace --all-targets --locked -- -D warnings` must pass.
- No new features: only what already exists is reorganized and redrawn; no command stops being accessible (menus, keys or command search).
- One commit per task (commits were in Spanish then), ending with `Co-Authored-By: <model> <noreply@anthropic.com>`.

## Review Focus

1. **1440px window:** no tab folds and every control shows name and key. Test in Task 2.
2. **Narrow window (1000px):** nothing overflows or gets cut off; names are dropped first, then the lowest-priority groups fold. Test in Task 2.
3. **Old tab shortcuts:** `TAB_HOME`, `TAB_LAYOUT` and `TAB_NOTATION` still open a tab that exists. Test in Task 1.
4. **Nothing is lost:** every command that was in the ribbon before is still in the ribbon or in a menu. Test in Task 1.
5. **Readable state:** a toggle that is on and a choice that is chosen are told apart from the off ones without hovering (fill, border and ink), and what is pending keeps the dashed border. Visual check in Task 4.

### Task 3: A single drawing grammar

**Files:**
- Modify: `crates/app-gpui/src/ui/toolbar.rs` (`frame`, `ink`, `large`, `tile`, `segment`, `items`, `group`, `ribbon_row`, `tabs`, `entry_pill`)
- Modify: `crates/app-gpui/src/ui.rs` (`HoverHint`: optional second line for `hint`)

**Interfaces:**
- Consumes: Tasks 1 and 2 (`ControlView` with `hint`; `Item` without `Column`).

Rules, from the spec:
- **At rest:** no background or border. **Hover:** `HOVER`. **Active or chosen:** `SELECT` + `SELECT_BORDER` border + `ACCENT_TEXT` ink, the same for toggle and choice (`CHOSEN`/`ON_ACCENT` and the `OUTLINE` border of off toggles go away). **Pending:** dashed `PENDING_OUTLINE` border and `MUTED` ink. **Disabled:** opacity 0.4.
- **Tile:** glyph in a 28px box; below it the name (10.5px, `SECONDARY`; `ACCENT_TEXT` if active) and below that the key (10px, `MUTED`), on two lines. No name in `Full` mode (glyph and key).
- **Choice track:** `FIELD` background, 2px padding, radius 9; the tiles inside, radius 7.
- **Group:** no card (`CARD`) or radius; name underneath, 11px, `MUTED`, left-aligned with the first tile. Spacing between groups: `Metrics::separator`.
- **Tabs:** 13px text (`MUTED`; `TEXT` for the chosen one and on hover) with a 2px `BLUE` indicator flush with the bottom line under the chosen one; no rounded background.
- **Status pill:** «Escribiendo · Negra con puntillo · Voz 2» (adds «con puntillo»/«en tresillo» and «Acorde» when active) with an 8px `BLUE` dot in front; when off, «Seleccionando · N para escribir» with a `MUTED` dot.
- **Tooltip:** `HoverHint` shows name and key on the first line and `hint` below it in `SECONDARY`.

- [ ] **Step 1: Write the failing tests** (pure, no GPUI, in `toolbar.rs`):
  - `entry_pill_text_names_every_active_modifier`: extract the pill text into a pure function `entry_text(writing, duration_label, dotted, triplet, voice, chord, key) -> String` and test the cases above.
  - `checked_toggles_and_choices_share_one_look`: extract a control's choice of colors into `fn look(role, checked, pending, enabled) -> Look { bg, border, ink, dashed }` and test that an active toggle and an active choice give the same `Look`, and that an off toggle has no border.
- [ ] **Step 2: Run** `cargo test -p levare toolbar`. Expected: FAIL.
- [ ] **Step 3: Implement** the drawing with `look` and `entry_text`.
- [ ] **Step 4: Run** `cargo fmt --all --check && cargo test --workspace --locked && cargo clippy --workspace --all-targets --locked -- -D warnings && cargo build -p levare`. Expected: PASS.
- [ ] **Step 5: Commit** `git commit -m "Ribbon: one button shape, underlined tabs and a clear state"`
